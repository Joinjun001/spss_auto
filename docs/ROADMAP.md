# 개발 로드맵

## 현재 MVP

- CSV/XLSX 원자료 업로드와 안전한 파싱
- 변수 측정 수준 추정 및 수동 검토
- 결측 코드 지정과 품질 경고
- 기술통계·빈도표·Pearson/Spearman 상관분석
- 그래프·Excel 결과 내보내기
- 단위 테스트와 GitHub Actions CI

## 다음 우선순위

1. 독립표본/Welch/대응표본 t-test, 효과크기 및 신뢰구간
2. 교차표 및 카이제곱 검정, 기대빈도 경고
3. Cronbach's alpha 및 역문항·척도 구성 지원
4. 연구 질문 기반 분석 추천과 가정 검정
5. 분석 이력·재현 가능한 보고서 및 로컬 배포 패키징

자동 추천은 분석을 강제하지 않으며 근거·가정·한계를 제공해야 합니다. 통계 수치는 SciPy 등 신뢰 가능한 구현과 대조 검증합니다.
