# 설문 분석 스튜디오 (spss_auto)

IBM SPSS 프로그램이나 라이선스 없이 **설문 원자료를 분석하는 로컬 웹 애플리케이션**입니다. CSV/XLSX 업로드 → 변수·코딩 검토 → 결측/품질 확인 → 기술통계·빈도분석·상관분석 → 표·그래프 → Excel 결과 다운로드를 지원합니다.

## 시작하기

Python 3.11 이상에서 다음 명령을 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `sample_data/example_survey.csv` 또는 직접 준비한 설문 원자료를 업로드하세요. **첫 행은 변수명, 이후 각 행은 응답자 한 명**이어야 합니다. 기존 SPSS 분석 결과표가 아닌 원자료를 입력합니다.

## 지원 기능과 한계

- CSV(UTF-8/CP949), XLSX 업로드: 최대 20MB, 10만 행, 300열. XLSX 압축 해제량 제한.
- 변수 유형 자동 **추정**(명목형/서열형/연속형/ID) 및 사용자의 수동 수정.
- 결측 코드 수동 지정, 중복 행·상수 변수·결측 데이터 경고. 자동 삭제·대체하지 않습니다.
- 기술통계: 유효 표본 수, 결측 수, 평균, 표본 표준편차, 중앙값.
- 빈도분석: 전체/유효 백분율, 막대그래프.
- Pearson/Spearman 상관: 상관계수, 유효 쌍 N, 양측 p, Pearson의 Fisher z 근사 95% CI. Spearman은 N<10에서 p를 제공하지 않습니다.
- 분석 결과 Excel 다운로드: 원자료는 결과 파일에 포함하지 않습니다.

**통계 해석 주의:** 자동 측정 수준은 통계적 타당성의 보증이 아닙니다. 설문 코딩북과 연구 설계, 변수의 독립성·분포를 확인하세요. 상관관계는 인과관계가 아닙니다. t-test, ANOVA, 회귀, 역문항 처리, 신뢰도 분석은 후속 개발 대상입니다.

**개인정보:** 애플리케이션 코드에는 업로드 원자료를 디스크·DB에 별도 저장하거나 외부 API로 전송하는 기능이 없습니다. 그러나 실행 서버·세션의 메모리 및 로그까지 무저장을 보증하지 않습니다. 민감한 설문 자료는 **개인 PC에서 로컬 실행**하세요. 공개 서비스로 배포하기 전 인증·세션 격리·보안 검토가 필요합니다.

## 개발

```bash
python -m pytest -q
python -m compileall -q app.py survey_core.py
```

`survey_core.py`는 통계 계산·데이터 검증을 담당하고 `app.py`는 Streamlit UI를 담당합니다. 루트의 `*자동화.py` 파일은 기존 SPSS 출력표 가공용 레거시 스크립트로 유지하며 새 앱과 독립적입니다. 코드·제품 설계는 jamovi의 측정 수준 검토 UX와 JASP의 연구자 중심 분석 흐름을 참고했으며 소스코드는 복제하지 않았습니다.

주요 오픈소스 의존성은 Streamlit(Apache-2.0), pandas(BSD-3-Clause), NumPy(BSD-3-Clause), SciPy(BSD-3-Clause), openpyxl(MIT)입니다. 배포 전 라이선스 고지를 재검토하세요.
