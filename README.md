# StatFlow

**StatFlow**는 연구자가 CSV/XLSX 설문 원자료를 업로드해 데이터 품질을 점검하고, 통계 분석·표·시각화·결과 내보내기를 수행할 수 있는 독립형 연구 데이터 분석 애플리케이션입니다.

현재 MVP는 원자료 업로드 → 변수·코딩 검토 → 결측/품질 확인 → 기술통계·빈도분석·상관분석 → 표·그래프 → Excel 결과 다운로드 흐름을 지원합니다.

## 시작하기

Python 3.11 이상에서 다음 명령을 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

첫 화면에서 **예시 데이터로 시작**을 선택하면 합성 설문 40명을 즉시 불러와 기능을 체험할 수 있습니다. 직접 준비한 데이터를 쓰려면 **내 파일 업로드**를 선택하세요. CSV/XLSX의 첫 행은 변수명, 이후 각 행은 응답자 한 명이어야 합니다.

## 지원 기능과 한계

- CSV(UTF-8/CP949), XLSX 업로드: 최대 20MB, 10만 행, 300열. XLSX 압축 해제량 제한.
- 변수 유형 자동 **추정**(명목형/서열형/연속형/ID) 및 사용자의 수동 수정.
- 결측 코드 수동 지정, 중복 행·상수 변수·결측 데이터 경고. 자동 삭제·대체하지 않습니다.
- 기술통계: 유효 표본 수, 결측 수, 평균, 표본 표준편차, 중앙값.
- 빈도분석: 전체/유효 백분율, 막대그래프.
- Pearson/Spearman 상관: 상관계수, 유효 쌍 N, 양측 p, Pearson의 Fisher z 근사 95% CI. Spearman은 N<10에서 p를 제공하지 않습니다.
- 분석 결과 Excel 다운로드: 원자료는 결과 파일에 포함하지 않습니다.

**통계 해석 주의:** 자동 측정 수준은 통계적 타당성의 보증이 아닙니다. 설문 코딩북과 연구 설계, 변수의 독립성·분포를 확인해야 합니다. 상관관계는 인과관계를 의미하지 않습니다. t-test, ANOVA, 회귀, 역문항 처리, 신뢰도 분석은 후속 개발 대상입니다.

**개인정보:** 애플리케이션 코드에는 업로드 원자료를 디스크·DB에 별도 저장하거나 외부 API로 전송하는 기능이 없습니다. 다만 실행 서버·세션의 메모리 및 로그까지 무저장을 보증하지 않습니다. 민감한 설문 자료는 개인 PC에서 로컬 실행하는 것을 권장합니다. 공개 서비스로 배포하기 전 인증·세션 격리·보안 검토가 필요합니다.

## 배포

현재 Streamlit 구조에는 Streamlit Community Cloud가 가장 직접적인 배포 대상입니다. `main` 브랜치의 `app.py`를 연결하면 이후 push가 배포 앱에 자동 반영됩니다. 자세한 절차는 `docs/DEPLOYMENT.md`를 참고하세요.

## 개발

```bash
python -m pytest -q
python -m compileall -q app.py survey_core.py
```

`survey_core.py`는 파일 파싱, 데이터 검증, 통계 계산, 결과 직렬화를 담당하고 `app.py`는 Streamlit UI를 담당합니다. 코드·제품 설계는 jamovi의 측정 수준 검토 UX와 JASP의 연구자 중심 분석 흐름을 참고했으며 소스코드는 복제하지 않았습니다.

주요 오픈소스 의존성은 Streamlit(Apache-2.0), pandas(BSD-3-Clause), NumPy(BSD-3-Clause), SciPy(BSD-3-Clause), openpyxl(MIT)입니다. 배포 전 라이선스 고지를 재검토하세요.
